# 遠見線上讀｜每週智能策展

**https://nomowho.github.io/gvm-weekly-read/**

輸入一個主題，自動從 **29,583 篇《遠見雜誌》紙本文章**（1987–2026）中挑出 4 篇相關報導，
產出可直接發送的每週導讀網頁。純前端，不需登入、不需安裝。

## 為什麼不會產生假文章、假連結

候選文章全部來自 `gvm.com.tw/magazine/published/{magId}`，也就是紙本雜誌的期別目錄頁。
每篇的標題、網址、出版年月、作者取自遠見官方內嵌的 JSON-LD 結構化資料，四個欄位綁在同一個物件裡。

網頁內建的索引就是這份資料，使用者只能從裡面挑，**選不出不存在的文章，也選不到網路即時新聞**。

## 使用方式

1. 輸入主題（例如「半導體」「永續金融」），按「自動選文」
2. 系統挑出 4 篇，摘要已帶入遠見官方版本，可直接改
3. 不滿意某篇按「換一篇」，從候選清單挑別的
4. 編者的話自己寫，或按「複製 AI 提示詞」貼到任何 AI，把回覆貼回來
5. 右側即時預覽，按「下載網頁」取得成品 HTML

連結會自動帶上 LINE 行銷追蹤碼，UTM campaign 與日期可在頁面上調整。

## 檔案

- `index.html` — 產生器
- `issues/` — 已發佈的期數存檔
- `data/index.json` — 紙本文章索引（約 3.9 MB，傳輸時 gzip 約 1.5 MB）

產生器與索引建置腳本在 Nomo 的工作專案內（`tools/gvm-weekly-read/`）。
